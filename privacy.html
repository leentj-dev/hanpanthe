1. 무엇을 위한 앱인가

"한판더" 앱은 채널 운영자 본인이 YouTube Data API를 통해 자신의 유튜브 채널(한판더)에 영상을 업로드하고 메타데이터(제목·설명·썸네일·공개 예약)를 관리하는 데만 쓰입니다.

2. 접근하는 정보

운영자가 Google 계정으로 승인하면, 앱은 운영자 채널에 영상을 올리고 관리하는 데 필요한 YouTube 권한과 OAuth 토큰만 받습니다. 다른 사용자의 정보는 수집하지 않습니다.

3. 보관과 공유

OAuth 토큰은 운영자의 컴퓨터에만 저장되며 외부 서버로 보내거나 제3자와 공유·판매하지 않습니다. 광고나 분석 목적으로 쓰지 않습니다.

4. Google API 서비스 사용자 데이터 정책

이 앱이 Google API로부터 받은 정보의 사용과 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 이 앱은 YouTube API 서비스를 사용하며, 사용자는 YouTube 서비스 약관과 Google 개인정보처리방침의 적용을 받습니다.

5. 권한 철회

언제든 Google 계정 보안 설정에서 이 앱의 접근 권한을 철회할 수 있으며, 철회하면 저장된 토큰은 더 이상 쓸 수 없습니다.
